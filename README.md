# ⚡ Calculadora de Consumo Elétrico

Uma calculadora inteligente desenvolvida em Python para estimar o consumo mensal de energia elétrica de um aparelho.

## 🎯 Objetivo

O projeto tem como objetivo ajudar o usuário a estimar quanto um aparelho elétrico consome de energia por mês, considerando sua potência e o tempo médio de uso diário.

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 🐙 GitHub
- ⚡ Energia elétrica

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![GitHub](https://img.shields.io/badge/GitHub-Repository-black?logo=github)

## 🧮 Fórmula utilizada

O consumo mensal é calculado pela fórmula:

**Consumo mensal = (potência × horas por dia × 30) / 1000**

O resultado é apresentado em **kWh/mês**.

## ▶️ Como executar

1. Abra o arquivo `app.py`.
2. Execute o programa em um ambiente Python.
3. Informe o nome do aparelho.
4. Informe a potência do aparelho em watts (W).
5. Informe o tempo médio de uso diário em horas.
6. O programa exibirá o consumo estimado em kWh/mês.

## 📌 Exemplo

**Aparelho:** Geladeira

**Consumo estimado:** 45 kWh/mês
